## 原始日志格式与后续待办

每个JSON是 `[记录开始后的秒数, 串口原文]` 数组，保留该段收到的全部文本。它没有精确动作时间戳；“看到提示”与实际抬升/放回时间不完全同步，不能用采集开始时间直接计算阶跃延迟。UART1诊断约每400ms一行，统计表基于打印后的整数值，不代表完整500Hz融合数据。包含运动的整段标准差不能当作静态噪声。

尚待验证/处理：

- 当前前32次气压均值没有“温度稳定后再归零”的处理；飞行中不应持续重新归零。
- 融合参数是台架起点，尚未完成定高PID、融合高度回传或飞行闭环。起飞请求只锁存，不实际起飞。
