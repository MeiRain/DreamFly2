## 数据与统计口径

- `capture.jsonl.gz`：完整只读采集，逐行包含主机 UTC 接收时间、阶段名及串口原文；有效行还保留 G/U/M 数组。
- `summary.json`：阶段统计、筛选规则及代表性原始行。
- 动作阶段包含拿起、回平、转动和手抖，表中动作均值只选目标方向主轴角速度大于 5 deg/s、其他两轴绝对值各小于主轴 35% 的样本：右倾 91 点、低头 135 点、顺时针偏航 104 点。完整数据未删去反向或跨轴动作；该筛选用于分离动作，不能替代独立角度基准。
- 静止基准和最终保持均取最后 250 个有效样本。
- 初次采集串口短暂断开，重连后继续记录；准备阶段有 83 行候选不可用，重连首行不完整，均未用于上述动作统计。动作阶段及末段解析行均为 `valid=1`。
- 串口未输出 MCU 采样时间，主机可能成批接收数据；不以接收时间积分角度，也不由此声称控制延迟或准确采样周期。

## 结论范围

三轴计算反馈方向及停止动作后的预览回落符合预期。本轮没有发送任何串口控制命令，没有写参数、写 Flash、自动编译或烧录，也没有接入实际电机闭环。部分拿取/跨轴动作使 P 输出触及 ±100 的占位限幅，不能把本轮测试视为飞行 PID 已调好、推力分配已验证或允许起飞。

后续是拆桨、受限输出的实际电机反馈验证，再逐步完成内环调参与姿态外环。
