# 六轴姿态解算台架调参记录（2026-10-28）

本轮只调整 Mahony 六轴姿态解算比例增益，未接入飞行控制或 Flash 写入。

## 暂定结果

- 六轴：`ATTITUDE_6AXIS_KP = 0.5f`，`ATTITUDE_6AXIS_KI = 0.0f`。
- 九轴保持 `KP = 0.2f`、`KI = 0.1f`，未参与本轮调参结论。
- 两轮的滤波、加速度门限与解算周期设置保持不变。
- 六轴解算配置周期 2 ms；UART1 日志周期约 20 ms（50 Hz）。
- 这是电机停止条件下的台架暂定参数，尚未验证电机振动和实际飞行。

## 数据格式

各 JSON 的 `rows` 为 `[采集开始后的秒数, 原始串口行]`。

串口行：`imu6,tick_ms,cal,ax,ay,az,gx,gy,gz,roll,pitch,yaw`。

加速度为 g，角速度为度/秒，姿态为度；`cal=1` 表示水平加速度校准成功。
日志使用飞控内部轴方向，与匿名上位机显示方向的变换无关。

`imu_statistics.csv` 为各段最后 5 秒统计。带 `hold` 或 `motion` 的片段可能仍包含手持运动，不能当作静止噪声统计。

## 对比过程

1. `kp02_ki0_*`：KP=0.2、KI=0。静止横滚/俯仰标准差约 0.010/0.008 度。
   右倾返回段相对加速度参考的横滚误差，从前 2 秒均值约 -0.35 度，降至最后 4 秒约 -0.07 度。
   俯仰返回段对应误差从约 -0.36 度降至最后 2 秒约 -0.14 度。
2. 首次尝试第二轮时，ELF 已含 KP=0.5，但 UART 运行计时连续，静止恢复拟合增益仍约 0.21。
   此批 `static/roll_hold/roll_return` 保留在 `/tmp/dreamfly-imu-tuning-round2`，不纳入这里的正式对比。
3. 用户重新下载并复位后，计时重新开始、校准成功。`kp05_ki0_*` 为此后数据。
   右倾返回段按小角度模型拟合的比例修正增益约 0.455，与 KP=0.5 相符（近似估计，非直接读取运行参数）。
   横滚读取初值约 -0.39 度，后段约 +0.05 度；俯仰读取初值约 -0.38 度，后段约 -0.03 度。
4. 完成前后/左右较快摆动。`kp05_ki0_motion.json` 结束时仍在运动，故补采 `kp05_ki0_motion_tail.json`。
   后续静止段横滚约 +0.10 度、俯仰约 -0.03 度，没有观察到持续振荡，暂时保持 KI=0。

## 解释范围

- 手持约 30 度倾斜没有独立测角基准。由同一加速度计计算的重力角只作为一致性参考，不代表绝对角度精度。
- 各轮动作幅度、速度并不完全相同；不能直接用动作中的最大角度或误差峰值评判增益优劣。
- 多段通过分别开启串口采集取得，放回动作可能早于返回段采集开始；不据此声称精确的“放回后几秒恢复”。
- 六轴偏航缺少绝对航向参考。本轮运动含人工转向，不以偏航首尾差判定算法漂移或宣称偏航已调好。
- 尚未启用匿名在线调参，也没有自动烧录、编译或写入 Flash。
