# 开发与协作

[返回项目首页](../README.md) · [文档索引](README.md)

## 开发路线

### 1. 建立基础

整理仓库、完成 CubeMX 和 FreeRTOS 基线，并逐项验证飞控板外设、传感器、遥控和 Wi-Fi 调试链路。

### 2. 恢复飞行

完成姿态解算、串级控制、电机混控和安全状态管理，使 DreamFly2 恢复并稳定实现自稳飞行。

### 3. 完成定高与定点

接入高度和光流信息，逐步完成高度估计、水平运动估计、定高飞行和室内低空光流定点。

### 4. 整理发布

完善自动起降、参数管理、调试工具、使用说明和开发记录，发布可复现的开源版本。

## 协作方式

- 使用 Issue 记录待办事项和问题。
- 每项任务由一人负责实现，另一人检查或实际测试。
- 使用独立分支开发，通过 Pull Request 合入 `main`。
- `main` 分支保持可编译、可烧录。
- 修改公共接口、通信协议或硬件定义前先进行讨论。
- 硬件问题、调试过程和关键结论保留简短记录。
