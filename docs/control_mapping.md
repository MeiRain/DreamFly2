# 遥控映射与姿态串级控制

[文档索引](README.md) · [单回中油门约定](throttle.md)

更新日期：2026-10-29。横滚、俯仰已接角度—角速度双环，偏航直接控制角速度；油门控制基础PWM。控制结构已接通，但初值尚未经过本版编译、板级方向核对或飞行调参。

## 通道与目标

所有输入为1000～2000。横滚、俯仰、偏航机械回中为1500；油门不回中，最低1000。映射函数为 `Application/flight.c` 的 `flight_map_control()`，输出 `flight_target_t`；非法指针、通道或模式使函数返回false且不修改输出。

| 目标 | 1000 | 1500 | 2000 |
|---|---:|---:|---:|
| 横滚 `roll_deg` | −20° | 0° | +20° |
| 俯仰 `pitch_deg` | −20° | 0° | +20° |
| 偏航 `yaw_rate_dps` | +90°/s | 0°/s | −90°/s |
| 自稳 `throttle_pwm` | 0 | 500 | 1000 |
| 定高候选 `climb_rate_mps` | −0.5m/s | 0m/s | +0.5m/s |

机体系使用X向前、Y向左、Z向上：正横滚为右翼下沉，正俯仰为低头，正偏航为俯视逆时针。右推偏航杆请求顺时针，所以目标为负；这是本次接通实际偏航控制时对旧候选映射的修正。ANO显示用的Pitch/Yaw取反只在发送层处理，不参与控制。

定高候选在1450～1550内为零升降速度，死区外连续映射到±0.5m/s。例如1750约为+0.222m/s。该模式及光流定点控制尚未接入；`FLIGHT_MAPPING_MODE` 当前固定为自稳，改成其他模式不会自动得到对应飞行控制，也不会响应SW4切换模式。

## 双环如何连接

```text
横滚／俯仰摇杆 → 目标角度（deg）
                         ↓ 与六轴实测角度比较
                 角度外环 → 目标角速度（deg/s）
                                      ↓ 与陀螺仪角速度比较
                              角速度内环 → PWM修正
偏航摇杆 ─────────────────→ 目标角速度 ──↑
油门摇杆 → 基础PWM ──────────────────→ 混控 → 电机
```

- `flight_angle_control()`：计算横滚、俯仰角度误差，输出限幅后的角速度目标；偏航直接传递摇杆角速度请求。
- `flight_rate_control()`：目标角速度减去陀螺仪实测角速度，计算三轴PWM修正。
- `flight_process_control()`：读取一致的数据快照，检查有效性，依次调用上述两环、混控及唯一电机输出入口。
- 私有 `flight_reset_control()`：清空两个角度PID及三个角速度PID的历史；停机、输入失效或超时时使用。

两环在同一帧有效IMU与六轴姿态发布后执行，标称周期2ms（500Hz）。传感器任务在同一调度锁内发布陀螺仪、姿态、新鲜度和待处理标记，避免新角速度配到旧角度。没有新帧时不重复运行PID；最后一个有效控制结果最多保留20ms。

横滚、俯仰回中请求水平姿态，因此静止保持倾斜时仍会产生扶平修正。偏航回中请求零角速度，不主动返回原航向，不使用九轴演示结果或磁力计作飞行航向锁定；六轴不能保证绝对航向长期不漂移。

## 当前初始参数

参数在 `Application/flight.c` 的 `flight_init()` 集中初始化；这些是待验证初值，不是已经调好的飞行参数。

| 环路 | Kp | Ki | Kd | 输出上限 |
|---|---:|---:|---:|---|
| 横滚角度 | 3 | 0 | 0 | ±100 deg/s |
| 俯仰角度 | 3 | 0 | 0 | ±100 deg/s |
| 三轴角速度，各自独立 | 2 | 0 | 0 | 当前实际输出模式每轴±20 PWM计数 |

外环初始P参考江科大的量级，内环保留最近确定的P=2。Ki/Kd仍为0，因此当前是串级P控制；结构支持后续分别调节P/I/D。`FLIGHT_RATE_TEST_OUTPUT_LIMIT=20` 仍生效，如果U已触及±20，单独继续增大Kp不会提高最大修正。

积分门控已接入：只有当前输出开关开启、输入有效、已经授予运行许可且油门大于1100时才允许积累；进入运行的首个有效周期可能仍禁用积分，下一帧才启用。上锁、等待、低杆停机、失联或无效数据清空两环历史，停机预览不积累。Ki=0也清空对应积分。

通用 `Common/pid.c` 保留积分分离与积分限幅，并拒绝把自身输出进一步推向饱和的积分增长；仍允许反向误差消退积分。它没有加入电机混控饱和反馈，满杆可能导致纠偏被裁剪，不能把此简单限幅当作完整混控去饱和。

现有UART2在线调参和Flash记录仍只有四个姿态解算增益，本次没有扩展为飞行PID参数。修改角度／角速度增益目前需修改初始化参数，由用户编译下载。

## 混控与输出许可

M1右后、M2右前、M3左前、M4左后；代码按M1/M3逆时针、M2/M4顺时针计算。设基础PWM为T，横滚／俯仰／偏航修正为R/P/Y：

```text
M1 = T - R + P - Y
M2 = T - R - P + Y
M3 = T + R - P - Y
M4 = T + R + P + Y
```

T使用`throttle-1000`，范围0～1000；混控和电机驱动统一限幅0～`MOTOR_PWM_MAX=1000`，ARR=999时比较值1000对应100%占空比。PWM不是推力或转速测量。零基础PWM的候选四路均为零。

`flight_write_motors()`仍是唯一调用`motor_control()`的位置。保留 `FLIGHT_RATE_TEST_ENABLED` 开关名以兼容已有配置；值1现在允许串级控制输出，值0仍只做计算预览，只有解锁顺序短转可以转动电机。它不切换为另一个自动飞行模式。

| 状态 | 实际输出 |
|---|---|
| 上锁、失联或必要数据失效 | 四路为0 |
| 解锁提示 | M3→M4→M1→M2，各PWM=100转200ms，间隔300ms |
| 等待低杆准备、确认或等待上推 | 四路为0 |
| 有运行许可且候选有效，开关为1 | 基础PWM叠加串级修正，单电机0～1000 |
| 开关为0 | 除解锁短转外，四路为0 |

解锁短转后，三轴1450～1550且油门≤1100保持200ms，再保持三轴居中上推到≥1200才授予运行许可。运行后可以操作三轴，油门经过1500不停机；拉低到≤1100停止并要求重新低杆确认。待飞15秒无操作自动上锁，运行后不应用该计时。

遥控数据超过300ms、必要IMU/姿态无效或控制结果≥20ms过期时停止并上锁。恢复数据不自行重启。失联停机仍是本阶段验证策略；定高、定点、自动起降、可靠落地判定和正式飞行失效处置需另行接入。Flash保存只允许在上锁时，并通过同一电机出口保证零输出。

## UART1与本版核对

UART1为115200、8N1，每20ms一行。`S`是三轴目标角速度，`G`是实测陀螺仪角速度，单位均为deg/s；`U`为PWM修正，`M`为候选混控，`O`为实际写给驱动的命令。`run`只表示串级电机输出已启用，不包括解锁短转，也不代表已经离地。

```text
rate: S=0.0,0.0,0.0 G=0.0,0.0,0.0 U=0.0,0.0,0.0 M=0500,0500,0500,0500 O=0000,0000,0000,0000 run=0 valid=1
```

示例为油门1500、三轴回中、机体水平静止且上锁。无候选时M为横线；无有效控制数据时输出`rate: INVALID boot=... imu=... cal=... rc=...`。`valid`只表示候选有效，不能单独判断正在运行。发送缓冲增至192字节，UART2协议和RX处理未改变。

用户编译下载后，先拆桨核对：

1. 上锁、三轴居中，右侧压低并保持：S横滚应为负，M1/M2应大于M3/M4；静止倾斜不再使修正归零。O仍为0。
2. 机头压低并保持：S俯仰为负，M2/M3应大于M1/M4；放平后修正接近0。
3. 保持机体水平，右推横滚杆：S横滚为正，M3/M4增大。向前推俯仰杆：S俯仰为正，M1/M4增大。右推偏航杆：S偏航为负，M1/M3增大；回中请求零角速度。
4. 按原低杆流程解锁并请求运行，核对O与M对应；拉低、上锁、失联及恢复后不自动重启的行为保持。

外环初值和±20修正限幅仍须实测，拆桨只能确认数据链和方向，不能替代带负载的动态调参。本版助手没有编译、烧录或进行新一轮板测。
