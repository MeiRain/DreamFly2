# 遥控目标映射

[文档索引](README.md)

当前固件默认启用拆桨角速度台架模式：完成解锁、回中和再次上推油门后会实际转动电机。当前操作与输出限制见文末“拆桨角速度台架模式”；前面的计算预览记录对应此前阶段。

映射位于 `Application/flight.c` 的 `flight_map_control()`，返回 `flight_target_t` 候选目标。它不运行PID、不切换飞行模式、不授权起飞，也不操作电机；后续控制器必须另外检查状态及估计有效性。

## 通道与范围

输入沿用1000～2000，中位1500。横滚、俯仰、偏航使用遥控器已有的采样死区，本函数不重复增加。正负号按通道数值建立，实际机体轴与电机反馈方向仍须板级核对。

| 目标 | 1000 | 1500 | 2000 |
|---|---:|---:|---:|
| `roll_deg` | −20° | 0° | +20° |
| `pitch_deg` | −20° | 0° | +20° |
| `yaw_rate_dps` | −90°/s | 0°/s | +90°/s |
| 自稳 `throttle_pwm` | 0 | 500 | 1000 |
| 定高 `climb_rate_mps` | −0.5m/s | 0m/s | +0.5m/s |

自稳模式（`FLIGHT_MODE_STABILIZE`）的基础油门沿用旧工程 `throttle - 1000`，只生成候选比较数值，`climb_rate_mps=0`。它不是实际推力或电机转速；现有电机驱动还有0～900限幅，未来接入时需统一分配与限幅，不能直接认为1000可原样输出。

定高模式（`FLIGHT_MODE_ALT_HOLD`）的 `throttle_pwm=0`，油门1450～1550内产生零升降速度，死区外按剩余450个通道单位连续映射到上升/下降速度上限。例如1750对应约+0.222m/s，1551只产生很小的正速度，不从固定速度跳起。

该油门死区是“回中保持”语义，与遥控器采样抖动死区用途不同。当前尚未实现回中刹停、锁定高度、速度PID及悬停基础油门，零速度候选值本身不等于高度保持。

## 接口与调用

```c
flight_target_t target;
bool valid = flight_map_control(&control, FLIGHT_MODE_ALT_HOLD, &target);
```

任一通道超出1000～2000、模式不支持或指针为空时返回false，输出保持不变。函数本身不知道数据年龄；控制任务只有在遥控连接有效、接收数据未超过300ms时才调用，失联时清零调试快照并标记无效。

控制任务当前只发布候选值，原有角速度PID仍以零角速度作为台架目标，未把目标倾角误接到角速度环。解锁、电机顺序提示、回中和起飞请求判断保持原样；未解锁时仍可预览摇杆映射，不能把该预览视为飞行授权。

`Application/flight.h` 的 `FLIGHT_MAPPING_MODE` 目前为 `FLIGHT_MODE_STABILIZE`，只选择调试预览算法。需要预览定高映射时改为 `FLIGHT_MODE_ALT_HOLD`；这不会更改无线模式标志或响应SW4模式请求。

UART1 当前只输出内环与混控预览，格式见下节。目标映射仍存于 `s_data.target`，不再通过旧的轮播调试页打印。

已完成提取映射公式的数值检查：两模式端点/中位、1001个油门值的单调性、死区与边界、未使用字段归零、非法输入及失败不改输出。未进行固件编译或新板级验证。

## 电机输出入口

`flight_process_remote()` 只推进解锁、回中等待和起飞请求状态；`flight_process_control()` 在本轮处理结束时调用私有的 `flight_write_motors()`，统一生成四个电机的 PWM，再调用一次 `motor_control()`。即使没有新的 IMU 样本，也会处理电机停转。

| 状态 | 当前电机输出 |
|---|---|
| 已上锁、失联或 IMU 失效后上锁 | 四路为 0 |
| 解锁短转提示 | M3→M4→M1→M2（左前→左后→右后→右前），各 PWM=100、转 200 ms，间隔 300 ms |
| 等待回中、确认回中、等待上推油门 | 四路为 0 |
| 已产生起飞请求 | 四路仍为 0，实际飞行控制尚未接入 |

电机驱动初始化时保持零输出。Flash 保存接口仅在已上锁且调度锁定时复用同一输出入口，确保停桨；其他任务不直接写电机。

后续混控应在该入口按实际飞行状态接入，不在遥控处理、PID 计算或调试函数中分别写 PWM。当前没有新增飞行授权或直接油门输出；后续的混控计算预览见下节。

本次整理仅做静态检查和离线时序对照，未编译、下载或进行新一轮电机实测。解锁提示的参数和已确定的起飞请求流程保持原样。

2026-10-28 根据用户确认的实机位置调整了解锁提示顺序：M3 左前、M4 左后、M1 右后、M2 右前。仅改变提示顺序，电机编号、PWM 引脚和未来混控的电机身份不变。新提示顺序尚待重新下载验证；此前通过的是 M1→M2→M3→M4 顺序。

## 角速度内环与混控计算预览

本阶段只运行计算，不把结果送入 `flight_write_motors()`。实际电机行为仍是解锁短转及其他状态停桨。现有内环暂以三轴 `0 deg/s` 为目标，使用陀螺仪 `deg/s` 测量值，沿用占位参数 `KP=1、KI=0、KD=0`，积分禁用；不代表已经调好飞行参数。横滚/俯仰的目标倾角未接入角速度环，角度外环尚未实现。

计算暂采用机体系 X 向前、Y 向左、Z 向上：正横滚为右翼下沉，正俯仰为低头，正偏航为俯视逆时针。实际 IMU 是否与此一致仍待板级核对；ANO 显示用的 Pitch/Yaw 取反不参与计算。

按用户最后更正，候选旋向采用 M1/M3 逆时针、M2/M4 顺时针，位置为 M1 右后、M2 右前、M3 左前、M4 左后。设基础油门为 T、三轴 PID 修正为 R/P/Y，均以 PWM 比较计数为单位：

```text
M1 = T - R + P - Y
M2 = T - R - P + Y
M3 = T + R - P - Y
M4 = T + R + P + Y
```

`flight_mix_motors()` 是 `flight.c` 私有的纯计算函数。基础油门来自现有自稳映射，允许 0～1000；零油门预览四路归零，其他结果逐路限幅到 0～900，四舍五入为整数。上下限裁剪会改变控制力矩，后续实际接入仍需检查饱和处理。上限统一使用 `motor.h` 的 `MOTOR_PWM_MAX`，电机驱动的限幅行为不变。

新 IMU 样本、新鲜姿态和有限陀螺仪值才允许计算内环；混控预览还要求有效遥控输入且预览模式为自稳。结果存入 `s_data.motor_preview`，`motor_preview_valid` 只表示本轮候选计算有效，不代表已解锁、轴向已验证或允许飞行。没有新样本或输入无效时清空本轮预览；IMU 无效时复位三轴 PID 历史，避免沿用旧计算结果。

UART1 现固定为 115200、8N1，每 20 ms 只输出一行，不再轮播 IMU、气压、遥控、状态或高度数据；原来的两个调试模式宏已移除，不需要手动切换：

```text
rate: G=0.0,0.0,0.0 U=0.0,0.0,0.0 M=0500,0500,0500,0500 valid=1
```

`G` 为陀螺仪 XYZ 角速度（deg/s），`U` 为横滚/俯仰/偏航 PID 修正量（PWM 计数），`M` 为 M1～M4 混控预览。当前目标仍为三轴零角速度，四路预览从未送给电机驱动。无有效遥控或混控候选时，`M` 显示 `----,----,----,----`，`valid=0`；内环无有效数据时仅显示 `rate: INVALID imu=... cal=... rc=...`。其中 `imu` 检查初始化、样本/姿态有效性和新鲜度，`cal` 表示水平加速度校准，`rc` 表示遥控连接新鲜度。

UART2 保持原有匿名姿态及在线参数通信，参数仍只有四个姿态解算增益，尚未把内环 PID 接入读写或 Flash 保存。

2026-10-28 用户编译下载后，已通过 U1 只读采集完成右倾、低头、顺时针偏航的手持方向核对，三项计算反馈方向及停止后的回落符合预期。详见 [实测记录](measurements/2026-10-28/rate_preview/README.md)。尚未接入实际电机闭环，本次没有修改 PID 参数。

## 拆桨角速度台架模式

`flight.h` 的 `FLIGHT_RATE_TEST_ENABLED=1` 默认启用本阶段。必须拆除四个螺旋桨；本模式用于检查电机响应，不包含姿态角度外环、定高或起降控制。设为 `0` 并重新编译下载，可恢复为只有解锁顺序短转、内环仅作计算预览的行为。

### 当前限制

| 项目 | 设置 |
|---|---|
| 三轴角速度目标 | 全部为 0 deg/s，不跟随横滚/俯仰/偏航摇杆 |
| 内环增益 | KP=1、KI=0、KD=0，积分关闭 |
| 固定基础 PWM | 100，实际驱动不采用 `throttle-1000` 的基础值 |
| 三轴修正量 | 每轴 ±20 PWM 计数 |
| 每电机命令上限 | 160；PWM 周期 ARR=999 时最高约 16% 占空比，不代表推力百分比 |
| 进入条件 | 已连接、必要 IMU/校准和新鲜 PID 数据有效，完成解锁短转、四轴回中至少 200 ms，再把油门推到 ≥1600 |
| 油门停止条件 | 回到 ≤1550，停止并返回等待回中；1551～1599 为进入后的滞回区间 |
| 失效条件 | IMU 不可用/非有限、PID 结果距所用样本 ≥20 ms，或遥控超过 300 ms 未更新，停止并上锁 |

限制在 `flight.c` 的 `FLIGHT_RATE_TEST_BASE_PWM`、`FLIGHT_RATE_TEST_OUTPUT_LIMIT`、`FLIGHT_RATE_TEST_MAX_PWM`、`FLIGHT_RATE_TEST_TIMEOUT_MS` 中。三轴各 ±20、基础值 100 时，理想混控范围为 40～160；混控函数仍显式执行 0～160 限幅。保持有限输出不是可装桨飞行的依据。

PID 仅在新 IMU 样本到达时计算。两次新样本之间保留最后的有限输出，但只允许保留至 20 ms；逾期会清空 PID 历史并使飞控上锁。恢复数据后不自动重转，须重新完成解锁和回中操作。上锁时才允许 Flash 保存，保存仍复用唯一电机出口写零。

### UART1 与操作

UART1 仍为 115200、8N1，20 ms 一行。未运行台架时可见有效候选 M，但实际命令 O 为零：

```text
rate: G=0.0,0.0,0.0 U=0.0,0.0,0.0 M=0100,0100,0100,0100 O=0000,0000,0000,0000 run=0 valid=1
```

触发台架后，静止时预计四路 O 接近 100，`run=1`：

```text
rate: G=0.0,0.0,0.0 U=0.0,0.0,0.0 M=0100,0100,0100,0100 O=0100,0100,0100,0100 run=1 valid=1
```

`O` 记录实际写给驱动的 M1～M4 PWM 命令，不是电机转速或推力测量；`run` 仅表示内环台架输出，不包含解锁顺序短转。`valid=1` 只表示候选计算有效，不能单独作为正在运行的判断。无效时显示简短状态及 O，`age` 为距最近 PID 所用样本的毫秒数。

1. 用户编译下载，拆桨、平放上电，遥控器保持连接，先确认 O 为四个零。
2. 内八解锁，观察左前→左后→右后→右前依次短转并停止。
3. 四轴回中保持约 1 秒，确认 `run=0`、O 为零。回中本身不启动台架。
4. 稍微上推油门到 ≥1600，保持不动。预期 `run=1`、O 接近四个 100；继续上推不增加基础输出。
5. 在助手分阶段提示下右倾、低头、俯视顺时针转动，核对 O 的右侧/前侧/M2-M4 差分及实际电机速度变化；停止动作后四路应回到接近 100。
6. 油门回中或拉低，确认停止；重新触发前必须再次确认回中。另测台架运行时关闭遥控器，确认失联上锁并停止，恢复通信后不自动重转。

若 O 有命令而电机没有起转，应先停止并反馈起转现象，再确定基础 PWM，不能据此宣称闭环方向错误或直接增加飞行油门。本阶段尚未完成电机运行验证；用户已编译下载，U1 已确认上锁时 O 为四个零、run=0。

本次助手只修改手写 Application 和说明文档，没有编译、烧录或发送串口控制命令；用户已自行编译下载。离线已检查限幅、等待回中、触发/停止滞回、失效上锁、禁止自动重启和计时回绕的行为模型，并核对 UART2 参数处理保持原样；这些检查不能替代上述板级测试。
