# DreamFly2 遥控器操作规划

[返回项目首页](../README.md) · [文档索引](README.md)

当前飞控临时启用了拆桨角速度台架模式：解锁短转、四轴回中后，再上推油门会实际低速驱动四电机；回中或拉低停止。此行为仅用于台架，参数与完整操作见 [台架模式](control_mapping.md#拆桨角速度台架模式)，不代表下文规划的一键起飞已实现。

当前只保留两个页面，第三页暂不实现，后续需要时再安排四轴校准。无线通信和摇杆、按键读取已完成实机验证；本次两页布局及 RAM 校准入口等待实机验证。起降、模式切换与 Flash 校准参数保存尚未实现；解锁手势及电机短转提示已接入，等待拆桨验证。

| 页面 | 内容 |
|---|---|
| 主页面（上电默认） | 顶部左侧信号、中间 FLIGHT、右侧飞机电池图标；左列 R/P、右列 Y/T；底部四位高度和右下角飞行模式 |
| 遥控器页 | 顶部左侧信号、中间 REMOTE、右侧遥控器电池图标；中部 LH/LV、RH/RV 实时值；底部左侧遥控器电压、右侧长按校准提示，在这一页完成摇杆校准 |

不再单独设置菜单页、校准提示页或结果页。操作结果以短暂弹窗提示，约 1.5 秒后恢复当前页面。

主页面角度四舍五入显示整数，保留正负号和 ±180° 范围，内部解算与通信仍保留原精度。高度按四位数字加正负号显示，单位 cm；显示范围 ±9999 cm，超范围显示 OVR，不截断数值。无数据时按固定宽度显示横线，保留符号位置和单位。

四轴数据保留协议范围 1000～2000，中位 1500。LH/LV 分别为左摇杆偏航／油门，RH/RV 分别为右摇杆横滚／俯仰。主页面已接入六轴 R/P/Y、电池电压、接收油门和传感器状态回传，等待实机验证；模式名称按回传标志显示，模式切换尚未实现；高度已接入气压相对高度，参考未就绪或数据过期时显示横线。姿态过期、初始化未完成或失联时也显示对应的无数据占位符，不把不可用值当成正常零值。信号图标为四根递增竖条，最高一根与标题字母的实际顶部、底部对齐；按最近 10 次发送成功率分档：0% 为零格，1%～29% 一格，30%～59% 两格，60%～89% 三格，90%～100% 四格。未点亮的竖条只显示底部短线；该图标表示发送成功率，不是射频 RSSI。

### 电池图标与遥控器电压

两页电池来源独立：FLIGHT 使用飞控回传电压，REMOTE 使用遥控器 ADC1 已有的第 1 路（PA0）电池采样。驱动只缓存同一帧的原始 ADC 值，上层独立滑动滤波并按 3.3 V 参考、1:2 分压换算；未重复启动 ADC。遥控器参考电压是标称值，后续可用万用表校准。电压超过 500 ms 未更新时隐藏旧值。

图标采用圆角电池外框、右侧正极和四个分格。本版启用试用电压档位：≥4.00 V 四格，3.85～4.00 V 三格，3.70～3.85 V 两格，3.50～3.70 V 一格，低于 3.50 V 空格。它只是图标分档，不代表精确的 25% 容量分段，也不作为电机停机阈值。

首次有效电压直接按档位显示；之后跨档需要约 0.03 V 的余量，避免边界反复跳格。飞控与遥控器分别保存图标状态和阈值，后续按各自负载实测调整；无有效电压仍显示问号。两组阈值位于 `Application/remote.c` 的 `s_flight_battery_levels_cv`、`s_remote_battery_levels_cv`，单位 0.01 V。

底部不再显示 LINK。右下角根据飞控回传标志显示中文模式：定点标志置位显示“定点”，否则定高标志置位显示“定高”，两者均未置位显示基础模式“自稳”；失联显示 `----`。若有传感器异常，该位置优先显示 `E:xx`。当前飞控台架程序尚未接入模式切换和完整飞行控制，定高／定点标志均为 0，因此连接后显示“自稳”；该标签不代表已经解锁或具备可飞行的自稳控制。SW4 模式切换仍未接入，遥控器不会自行修改回传模式。

主页面 `E:xx` 为传感器状态：`01` 表示 IMU 未就绪／异常，`02` 表示磁力计初始化失败，`04` 表示气压计初始化失败，多项可叠加。MAG/BARO 当前只报告初始化结果；详情见 [遥控通信协议](remote_protocol.md)。

校准成功弹窗显示 `CAL OK (RAM)` 和 `FLASH NOT SAVED`，仅修改本次运行的中点；保存参数和重启载入是待实现目标。

## 按键分工

面向操作者，SW4 为左侧功能键，SW2 为右侧功能键；SW5～SW8 为四方向微调键。物理方向与 GPIO 位的对应关系在实机核对后绑定，不根据按键编号推断方向。

| 操作 | 主页面 | 摇杆页 |
|---|---|---|
| SW2 短按 | 切换到摇杆页 | 切换到主页面 |
| SW2 长按 | 切换到摇杆页，不开始校准 | 四轴居中后长按，开始校准 |
| SW4 短按 | 请求切换飞行模式 | 返回主页面 |
| SW4 长按 | 请求起飞／受控降落 | 无操作 |
| SW5～SW8 | 四方向微调 | 仅本地查看，不发送微调 |

长按沿用当前驱动的 1.5 秒门限，每次按住只触发一次，长按后的松开不再产生短按。普通页面的模式和起降操作目前只弹出“尚未接入”的提示，不发送这些动作。

摇杆页可在未连接时查看实时通道；开始校准必须收到飞控未解锁的有效回传。摇杆页按住的方向键在返回主页面后必须先松开，再恢复微调用途，避免把本地操作带入飞行控制。模式切换只是请求，实际模式由飞控决定。

## 解锁、起飞与降落

### 当前台架验证

飞控已接入内八保持 1.5 秒切换解锁／上锁。解锁时电机按 M3 → M4 → M1 → M2（左前 → 左后 → 右后 → 右前） 依次短转，每个转 200 ms，电机之间停 300 ms，同一时刻只启动一个，总计约 1700 ms 后全部停止；上锁时保持零输出。按通道左／下约 1000、右／上约 2000 判断：LH（偏航）≥1900，LV（油门）、RH（横滚）、RV（俯仰）均 ≤1100。持续保持只触发一次，必须松开后再做内八；上电及故障恢复后也须先松开。

判断在控制任务中执行，需要有效遥控连接、完成加速度校准及有效的 IMU 姿态。300 ms 没有新遥控包或姿态超过 100 ms 未更新时清除解锁状态，恢复后不会自动解锁。短转期间同样执行上述检查，异常时终止短转。这是拆桨台架策略，实际飞行的失联处置须在接入油门和闭环控制前重新设计。

短转初始参数位于 `Application/flight.c`：`FLIGHT_ARM_SPIN_PWM=100`、`FLIGHT_ARM_SPIN_MS=200`、`FLIGHT_ARM_SPIN_GAP_MS=300`。当前 TIM3/TIM4 的 ARR=999，对应约 10% 占空比；它是待实测的起点，不保证电机一定起转。控制任务每 2 ms 推进计时，不使用阻塞延时；短转结束只停止电机，仍保持解锁。必须拆桨验证。任务若停止运行，软件计时也无法主动停机，当前尚未实现看门狗保护。

现有回传包的 ARMED 位反映该逻辑状态，协议长度不变。USART1 在状态变化时输出 `flight: ARMED` 或 `flight: LOCKED`，模式切换及起降仍未实现。

### 回中油门的起飞入口

操作顺序确定为：内八解锁 → 四个电机依次短转 → 停桨等待 → 四轴回中 → 再次上推油门请求起飞。短转期间的回中不计入；短转结束后，四轴均在 1450～1550 内连续保持 200 ms，才允许下一次油门上推。油门达到 1600 时记录一次起飞请求，回中经过 1500 本身不会触发。提前推高油门会继续等待四轴回中，不直接起飞。

当前只实现请求判断：USART1 输出 `flight: TAKEOFF REQUEST (controller not connected)`，电机仍保持停止。请求保持到上锁、失联或 IMU 失效时清除；后续高度控制接入时由飞行状态处理一次，不把它当作持续起飞命令。相关参数在 `Application/flight.c`，尚未经过板子验证。

SW4 长按的一键起飞／受控降落规划保留，目前仍是未接入提示；后续通过独立动作请求与确认机制接入，不根据按键持续电平直接启动电机。

| 飞控状态 | 操作 | 期望行为 |
|---|---|---|
| 已上锁、在地面 | 摇杆内八 | 飞控检查解锁条件，通过后解锁 |
| 刚解锁成功 | 自动提示 | M3 → M4 → M1 → M2（左前 → 左后 → 右后 → 右前） 依次低速短转，每个转 200 ms，中间停 300 ms，随后停止；不自动起飞 |
| 已解锁、短转结束 | 四轴回中，再上推油门 | 产生起飞请求；当前控制器未接入，保持停桨 |
| 已解锁、在地面 | SW4 长按 | 请求升至预设高度并保持 |
| 正在飞行 | SW4 长按 | 请求立即开始受控下降 |
| 正在降落 | 再次 SW4 长按 | 保持当前降落，不切换为起飞 |
| 已落地 | 飞控确认落地 | 停转并上锁 |
| 已上锁 | SW4 长按 | 不起飞，也不隐式解锁 |
| 状态未知或失联 | SW4 长按 | 不根据遥控器缓存状态推断起飞或降落动作 |

电机短转提示只在一次成功的解锁状态转换时触发，不因持续保持内八或重复通信帧反复触发。短转速度和持续时间需要台架验证后确定；预设起飞高度也在定高功能接入时确定，不在此处写死。

“紧急降落”在本项目中指立即请求受控下降，不是空中直接停桨。手势上锁已确定为松开后再次内八；紧急停桨交互尚未确定，不绑定到上述按键。

起飞必须依赖有效遥控连接、正常的必要传感器、可用的姿态／高度控制及已解锁状态。处于起飞过程时，SW4 长按请求转入降落，不再重复启动起飞。

遥控器发送明确的动作请求，飞控是执行状态的唯一判断方。一次“起降”按键事件应在形成请求时确定为起飞或降落，重复发送同一请求不能因状态变化被解释成相反动作。无线硬件 ACK 只表示数据传输成功，不能当作动作已经被飞控接受或完成。

当前 13 字节控制包只发送摇杆与按键状态，尚无独立动作请求字段；现有 18 字节回传也不能完整区分已解锁待飞、起飞中、飞行中和降落中。接入起降前需要同步完善两端协议与确认机制，不能仅用 ARMED 标志判断是否正在飞行。

## 摇杆校准

1. 从主页面短按 SW2，进入摇杆页，观察四轴实时值。
2. 四个轴全部放在中间位置；当前油门没有自动回中，需要手动居中。
3. 长按 SW2，触发一次校准，采集 60 次计算四轴中点。
4. 在原页面弹窗显示成功或失败；成功后继续观察四轴是否回到 1500。
5. 短按 SW4 或 SW2，返回主页面。

进入摇杆页本身不开始采集。采集按 5 ms 任务周期分步执行，每次最多取一个新样本，不使用采样等待循环或 `HAL_Delay()`；正常约 0.3 秒，超过 1 秒仍未完成则失败退出。采集期间暂停页面切换和控制包发送，但显示刷新与无线轮询继续执行；不接受起降请求。成功／失败后显示短暂弹窗，再恢复实时摇杆页。当前成功只更新 RAM；未来 Flash 保存也只能在确认未解锁时执行。

## RGB 驱动与验证

遥控器单颗 WS2812B 已由旧 GPIO 延时发送改为 TIM3_CH1 PWM + DMA，文件为 `Components/WS2812B/ws2812b.c/.h`，等待实机验证。它只处理颜色和发送，不判断遥控连接、按键或校准状态。

- PB4，TIM3 部分重映射；TIM3 时钟 72 MHz，PSC=0、ARR=89，位周期 1.25 μs。
- 0/1 码比较值分别为 22/65，高电平约 306/903 ns。
- 帧前、帧后各发送 200 个低电平槽，各约 250 μs；单灯一帧约 530 μs。
- DMA1 Channel6 使用 Normal、Memory-to-Peripheral、Word/Word；静态缓冲区 1696 字节，发送期间不改写。
- DMA 完成或错误回调停止发送并释放忙状态；驱动没有等待循环或软件纳秒延时。
- 单色快捷接口与渐变默认亮度约 8/255（已因实机观察刺眼而降低），原始 RGB 设置接口仍支持 0～255。渐变建议约每 20 ms 调用一次，速度随调用周期变化。
- DMA1 Channel6 与 I2C1_TX 复用，OLED 保持当前轮询 I2C，不同时启用该 DMA 通道。

本次未修改 CubeMX、CMake 或自动接入灯光规则。编译前在遥控器 `target_sources` 加入 `Components/WS2812B/ws2812b.c`，在 `target_include_directories` 加入 `Components/WS2812B`。

单色验证可在 `remote_init()` 中调用一次（已完成底层 TIM3/DMA 初始化之后），调用文件引用 `ws2812b.h`：

```c
ws2812b_init();
ws2812b_all_green();
```

需要自定义颜色时调用 `ws2812b_set_all(red, green, blue)`，再调用 `ws2812b_show()`。驱动从一个任务调用；不要在多个任务或中断中同时发帧，也不要复制另一个同名 HAL PWM 完成回调。

## RGB 与蜂鸣器提示方案（待确认，尚未接入）

| 情况 | RGB | 蜂鸣器 |
|---|---|---|
| 本机初始化完成 | 白色短亮后进入连接状态 | 一短声，只提示一次 |
| 上电等待连接 | 黄色慢闪 | 静音 |
| 连接成功、未解锁 | 绿色常亮 | 连接建立时两短声，之后静音 |
| 飞控确认已解锁 | 青色常亮 | 解锁状态变化时一短声 |
| 曾连接后失联 | 红色快闪 | 间隔重复两短声 |
| 任一端低电压 | 红色慢闪 | 间隔短声，OLED 区分电池来源 |
| 摇杆校准采集中 | 蓝色常亮 | 静音 |
| 校准成功／失败 | 绿色／红色短闪，随后恢复原状态 | 成功一短声，失败两短声 |
| 本机无线或摇杆初始化失败 | 红色快闪 | 间隔重复三短声 |

提示优先级：本机关键故障 > 曾连接后失联 > 低电压 > 校准提示 > 已解锁 > 已连接 > 等待连接。普通按键默认不鸣叫；连接成功、解锁和校准结果只在状态变化时触发，不在周期任务中重复触发。

蜂鸣器为有源器件，用开关时长和次数区分提示，不设计音阶。灯光动画和蜂鸣节奏由应用层按时间推进，不使用 `HAL_Delay()`，不为提示额外创建任务。低压告警阈值后续单独确定，不能直接把电池四格显示阈值当成停机或告警阈值。初始化未完成也不直接当成失败；飞控上电校准期间的 IMU 未就绪提示，不应立刻触发故障蜂鸣。
