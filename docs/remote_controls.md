# DreamFly2 遥控器操作规划

[返回项目首页](../README.md) · [文档索引](README.md)

当前只保留两个页面，第三页暂不实现，后续需要时再安排四轴校准。无线通信和摇杆、按键读取已完成实机验证；本次两页布局及 RAM 校准入口等待实机验证。起降、模式切换、电机短转提示与 Flash 校准参数保存尚未实现。

| 页面 | 内容 |
|---|---|
| 主页面（上电默认） | 飞行信息：R/P/Y、油门、高度；顶部信号、电量和飞行模式 |
| 摇杆页 | LH/LV、RH/RV 四轴实时数据，在这一页完成摇杆校准 |

不再单独设置菜单页、校准提示页或结果页。操作结果以短暂弹窗提示，约 1.5 秒后恢复当前页面。

四轴数据保留协议范围 1000～2000，中位 1500。LH/LV 分别为左摇杆偏航／油门，RH/RV 分别为右摇杆横滚／俯仰。主页面已接入六轴 R/P/Y、电池电压、接收油门和传感器状态回传，等待实机验证；模式和高度尚未实现，继续显示横线。姿态过期、初始化未完成或失联时也显示横线，不把不可用值当成正常零值。信号图标按最近 10 次发送结果的成功率分为 0～3 格。

主页面 `E:xx` 为传感器状态：`01` 表示 IMU 未就绪／异常，`02` 表示磁力计初始化失败，`04` 表示气压计初始化失败，多项可叠加。MAG/BARO 当前只报告初始化结果；详情见 [遥控通信协议](remote_protocol.md)。

校准成功弹窗显示 `CAL OK (RAM)` 和 `FLASH NOT SAVED`，仅修改本次运行的中点；保存参数和重启载入是待实现目标。

## 按键分工

面向操作者，SW4 为左侧功能键，SW2 为右侧功能键；SW5～SW8 为四方向微调键。物理方向与 GPIO 位的对应关系在实机核对后绑定，不根据按键编号推断方向。

| 操作 | 主页面 | 摇杆页 |
|---|---|---|
| SW2 短按 | 切换到摇杆页 | 切换到主页面 |
| SW2 长按 | 切换到摇杆页，不开始校准 | 四轴居中后长按，开始校准 |
| SW4 短按 | 请求切换飞行模式 | 返回主页面 |
| SW4 长按 | 请求起飞／受控降落 | 无操作 |
| SW5～SW8 | 四方向微调 | 仅本地查看，不发送微调 |

长按沿用当前驱动的 1.5 秒门限，每次按住只触发一次，长按后的松开不再产生短按。普通页面的模式和起降操作目前只弹出“尚未接入”的提示，不发送这些动作。

摇杆页可在未连接时查看实时通道；开始校准必须收到飞控未解锁的有效回传。摇杆页按住的方向键在返回主页面后必须先松开，再恢复微调用途，避免把本地操作带入飞行控制。模式切换只是请求，实际模式由飞控决定。

## 解锁、起飞与降落

| 飞控状态 | 操作 | 期望行为 |
|---|---|---|
| 已上锁、在地面 | 摇杆内八 | 飞控检查解锁条件，通过后解锁 |
| 刚解锁成功 | 自动提示 | 四个电机低速短转一次，随后停止；不自动起飞 |
| 已解锁、在地面 | SW4 长按 | 请求升至预设高度并保持 |
| 正在飞行 | SW4 长按 | 请求立即开始受控下降 |
| 正在降落 | 再次 SW4 长按 | 保持当前降落，不切换为起飞 |
| 已落地 | 飞控确认落地 | 停转并上锁 |
| 已上锁 | SW4 长按 | 不起飞，也不隐式解锁 |
| 状态未知或失联 | SW4 长按 | 不根据遥控器缓存状态推断起飞或降落动作 |

电机短转提示只在一次成功的解锁状态转换时触发，不因持续保持内八或重复通信帧反复触发。短转速度和持续时间需要台架验证后确定；预设起飞高度也在定高功能接入时确定，不在此处写死。

“紧急降落”在本项目中指立即请求受控下降，不是空中直接停桨。紧急停桨和手势上锁的交互尚未确定，不绑定到上述按键。

起飞必须依赖有效遥控连接、正常的必要传感器、可用的姿态／高度控制及已解锁状态。处于起飞过程时，SW4 长按请求转入降落，不再重复启动起飞。

遥控器发送明确的动作请求，飞控是执行状态的唯一判断方。一次“起降”按键事件应在形成请求时确定为起飞或降落，重复发送同一请求不能因状态变化被解释成相反动作。无线硬件 ACK 只表示数据传输成功，不能当作动作已经被飞控接受或完成。

当前 13 字节控制包只发送摇杆与按键状态，尚无独立动作请求字段；现有 18 字节回传也不能完整区分已解锁待飞、起飞中、飞行中和降落中。接入起降前需要同步完善两端协议与确认机制，不能仅用 ARMED 标志判断是否正在飞行。

## 摇杆校准

1. 从主页面短按 SW2，进入摇杆页，观察四轴实时值。
2. 四个轴全部放在中间位置；当前油门没有自动回中，需要手动居中。
3. 长按 SW2，触发一次校准，采集 60 次计算四轴中点。
4. 在原页面弹窗显示成功或失败；成功后继续观察四轴是否回到 1500。
5. 短按 SW4 或 SW2，返回主页面。

进入摇杆页本身不开始采集。采集按 5 ms 任务周期分步执行，每次最多取一个新样本，不使用采样等待循环或 `HAL_Delay()`；正常约 0.3 秒，超过 1 秒仍未完成则失败退出。采集期间暂停页面切换和控制包发送，但显示刷新与无线轮询继续执行；不接受起降请求。成功／失败后显示短暂弹窗，再恢复实时摇杆页。当前成功只更新 RAM；未来 Flash 保存也只能在确认未解锁时执行。
