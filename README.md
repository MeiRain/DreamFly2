# DreamFly2

DreamFly2 是一个基于 STM32F411、HAL 和 FreeRTOS 实现的微型四轴飞行器项目。

项目源自本科阶段的 DreamFly。在保留原有硬件和飞行经验的基础上，新版本将重新整理驱动、算法、飞行控制和调试工具，最终实现室内低空的自稳、定高与光流定点飞行。

## 单回中油门约定

遥控器采用油门上下轴不回中的单回中设计；横滚、俯仰、偏航仍自动回中。油门松手保持当前杆位，最低 1000、中位 1500、最高 2000。

| 模式 | 油门含义 | 中位含义 |
|---|---|---|
| 自稳 | 杆位连续映射基础输出，驾驶者手动调节高度 | 固定杆量，不保证悬停，不强制映射悬停基准 |
| 定高 / 光流定点 | 上半请求上升、下半请求下降 | 手动放入 1450～1550 死区，请求保持高度 |

- **校准**：三轴居中、油门拉到底，采集三轴中点和油门最低值；旧版四中点参数不能直接沿用。
- **解锁待飞**：内八解锁，电机依次短转后停桨；三轴居中且油门 ≤1100 保持 200 ms，再上推。当前自稳台架到 ≥1200 启动，低杆 ≤1100 停止；中位不停止。
- **待飞保护**：提前推高不能启动；待飞 15 秒无操作自动上锁；失联或必要数据失效上锁，恢复后重新执行解锁和低杆确认。
- **正式模式**：定高／定点低杆是下降请求，不能套用台架低杆停机逻辑；落地后手动上锁，可靠落地检测接入后再实现自动上锁。

当前台架基础 PWM 已跟随 `油门值 − 1000`，单电机输出范围 0～1000，三轴修正仍各限 ±20；解锁短转仍为 PWM=100。横滚／俯仰已接角度—角速度双环，偏航按摇杆控制角速度；初始参数仍待验证，定高、定点和一键起降尚未接入。完整规则与 PX4 对照见 [单回中油门控制](docs/throttle.md)。

## Flash 参数区配置

飞控使用末尾 128 KB（扇区 7）保存参数。在 `firmware/dreamfly2_flight/STM32F411xx_FLASH.ld` 的 `MEMORY` 中，将 Flash 的 `LENGTH = 512K` 改为 `384K`，RAM 配置不变：

```ld
FLASH (rx) : ORIGIN = 0x08000000, LENGTH = 384K
```

同时在飞控 `CMakeLists.txt` 的 `target_sources()` 中加入 `Core/Src/flash.c`。修改后重新构建。

`flight_init()` 自动加载参数；匿名上位机现已接入四个姿态解算增益的读取、修改、恢复默认和保存命令，支持 UART2 串口或 WiFi 双向透传。修改先在 RAM 生效，明确执行保存才写入 Flash；修改和保存要求飞控已上锁。UART2 报文读写、保存及掉电加载已通过实机验证；匿名上位机界面和 WiFi 透传尚待验证。详见 [在线调参](docs/ano_parameters.md) 和 [Flash 参数保存](docs/flash.md)。
